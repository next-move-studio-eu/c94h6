# Article examples

Place example article ZIP files here. Each example has two files:

- `{fileName}-cs.zip` — Czech version
- `{fileName}-en.zip` — English version

The `fileName` is the value from the translations `examples.items[].fileName` (e.g. `example-chess-intro`, `example-tactics`).

ZIP format: outer archive containing a single entry `content.zip`; inner `content.zip` contains `content.json`, optional `info.json`, and assets (thumbnail, images, etc.) as expected by the editor.
