# GDPR / Ochrana osobních údajů

## Offline aplikace

Tento editor **běží lokálně u vás**. **Neposílá** žádný obsah, uživatelská data ani osobní údaje přes internet.

- Vaše dokumenty a soubory zůstávají na vašem zařízení.
- Nepoužíváme analytiku, sledování ani telemetrii.
- Není vyžadován účet ani přihlášení.

Osobní údaje ve smyslu GDPR nezpracováváme, protože aplikace žádná taková data neshromažďuje ani nepřenáší.
